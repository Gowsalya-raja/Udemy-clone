
# Udemy Clone Website

This project is a simple **Udemy Clone Website** created using **basic HTML and CSS**. The main goal of this project is to practice frontend web development by recreating the layout and design of the Udemy website.

## Technologies Used

* HTML5
* CSS3

## Features

* Navigation bar
* Search bar
* Course categories
* Course cards
* Course images
* Course ratings and prices
* Promotional banner
* Footer section
* Responsive layout

## Purpose

This project was created to improve my understanding of:

* HTML page structure
* CSS styling
* Flexbox
* Responsive layouts
* Website component design

## Project Status

Completed as a frontend practice project using **HTML and CSS only**.
