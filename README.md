# 🎓 Udemy Clone Website

A responsive **Udemy Clone Website** built using **HTML5 and CSS3**. This project recreates the look and feel of the Udemy learning platform with a focus on layout, navigation, course sections, and responsive design.

## 🚀 Project Overview

This project was created to practice and demonstrate my frontend development skills using **pure HTML and CSS**, without using JavaScript, frameworks, or libraries.

The website includes a Udemy-inspired homepage with a navigation bar, search section, promotional banner, course categories, recommended courses, and footer sections.

## ✨ Features

* 📱 Responsive website layout
* 🧭 Udemy-inspired navigation bar
* 🔍 Search bar UI
* 🎯 Promotional/hero section
* 📚 Course recommendation sections
* 🏷️ Course cards with images, titles, ratings, and pricing
* 📂 Course categories
* 👨‍🏫 Instructor-related sections
* 🔗 Footer with useful links
* 🎨 Clean and structured CSS styling

## 🛠️ Technologies Used

* **HTML5** – Website structure and semantic elements
* **CSS3** – Styling, layout, Flexbox, Grid, and responsive design
